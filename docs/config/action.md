# Action configuration

## Workflow implementation

```yaml { .copy }
  - uses: publish-site/action@v2
    with:
        dir: site/ # CHANGEME
        url: https://api.example.com/ # CHANGEME
        privkey: ${{ secrets.PRIVKEY }}
        cert: ${{ secrets.CERT }}
```

## Input table


| input       | description                                                            |   | example                             |
| :------------ | ------------------------------------------------------------------------ | --- | ------------------------------------- |
| dir         | The directory to deploy                                                | * | site/                               |
| ip          | The API ip address/FQDN                                                | * | example.com                         |
| url         | Redundant legacy variable for ip. Both works                           |   | example.com                         |
| privkey     | The SSH Private key generated by the PKI script. Should be secret (!). | * | -----BEGIN OPENSSH PRIVATE KEY----- |
| cert        | Redundant legacy variable for private key                              |   | ${{ secrets.CERT }}                 |
| **required* |                                                                        |   |                                     |
